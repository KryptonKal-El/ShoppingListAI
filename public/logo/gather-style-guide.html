04 — Guidelines
Usage Notes

✅ Do

  • Use Forest (#3D7A63) for the wordmark on light backgrounds, white on dark
  • Keep the check-heart bullets Blush (#F9A8C9) with white checkmarks everywhere
  • App icon: white list lines on the flat Mint tile
  • Web and print: use the tile-free glyph — list lines in Sage on light surfaces, white on Forest
  • Keep Quicksand SemiBold (600) for all logo text
  • Use Cream (#FAFAF7) as the default app background

❌ Don't

  • Don't use the tiled app icon inside website headers — the bare glyph belongs there
  • Don't stretch or distort the logo proportions
  • Don't recolor the hearts or remove their checkmarks
  • Don't use colors outside the defined palette
  • Don't change the font family away from Quicksand
  • Don't place the logo on busy or clashing backgrounds

🎯 Logo Placement

  • App Store / Play Store → Icon tile only
  • Web app header → Tile-free glyph + name + tagline
  • Marketing site header → Tile-free glyph + name
  • Splash / onboarding → Stacked centered version
  • Social media profile → Icon tile (square crop)
  • Email footer → Tile-free glyph + name

📐 Spacing & Radius

  • App icon corner radius: 25% of icon width
  • Card corner radius: 16px standard, 24px large
  • Clear space around logo: 1× glyph height minimum
  • Heart shadow: 0 1.5px 1.5px rgba(44,92,74,0.3)
  • Base spacing unit: 8px grid
  • Card shadow: 0 4px 16px rgba(61,122,99,0.12)
